# План реализации

Отмечается по мере готовности. Фазы идут по порядку: каждая заканчивается рабочей сборкой и тестами.

## Телетекст и субтитры из него (2026-09-13)

- [x] DVB-телетекст из HLS (MPEG-TS): свой читатель дорожки в экстракторе (`TeletextHlsExtractorFactory`), разборщик страниц (`teletext/Ttx.kt`: Хэмминг, магазины, подстраницы, Fastext, наборы знаков, раскладка уровня 1 в сетку 40×25), экран телетекста (`TeletextLayer` / `TeletextView`: цвета, мозаика, двойная высота, мигание, скрытый текст) — пункт меню «Телетекст» и клавиша TEXT; субтитры — текстовая дорожка «Телетекст» (страница 888 или объявленная) в «Звук и субтитры». Поиск каналов с настоящим телетекстом — `tools/find_teletext.py` (многие каналы объявляют дорожку, но данных не шлют — «Первый» у провайдера из запроса). Проверено: юнит-тесты на записанных потоках трёх публичных каналов (`tools/samples`: НТВ Мурманск, Россия 1 Калининград, ТВ Центр Мурманск — страницы, кириллица, Fastext, субтитры); на эмуляторе — синтетический HLS (`tools/teletext_mock.py`: настоящее видео «Первого» и вставленные пакеты телетекста): меню и клавиша TEXT, страницы 100, 105 (мозаичный логотип, кириллица) и 141 (цвета, двойная высота, нижняя строка ссылок), набор номера, красная кнопка, субтитры (жёлтый текст в окне, две строки, гашение пустой страницей). Дальше в тот же день: экранная клавиатура справа от страницы (цифры, цветные кнопки, ⌫, индекс, стоп подстраниц, фон) с зонами фокуса «клавиатура / страница», меню телетекста по удерж. OK или MENU (клавиатура, фон, скрытый текст, подстраницы, закрыть), прозрачный фон поверх видео, уровень 1.5 (X/26: «ё» в программе ТВЦ теперь есть, проверено на записанной странице), двойная ширина. Проверено на эмуляторе: клавиатура и её кнопки, прозрачный фон (видео видно сквозь страницу), меню, скрытая клавиатура (страница по центру), закрытие из меню; субтитры настоящей страницы 888 ТВЦ (образец) показываются. Затем клавиатура переделана по образцу PIN «Google» (↑/↓ — ряд, ← / OK / → — кнопка ряда, круг d-pad над клавиатурой, ряд `‹ 100 ›`, зон фокуса нет). Не проверено: настоящий телевизор (в том числе клавиша TEXT и цветные кнопки пульта), субтитры из живого эфира, мигание, скрытый текст, автолистание подстраниц, двойная ширина на настоящей странице (только юнит-тест), тач по кнопкам, телетекст в прямом TS без HLS.

## Воспроизведение: поток провайдера, который «висел» (2026-09-10)

- [x] Потоки вещательных кодеров (non-IDR ключевые кадры + recovery point, чересстрочное H.264, MP2 / AC-3, телетекст) не стартовали: ExoPlayer не видел ключевых кадров. Воспроизведено на эмуляторе (чёрный экран и бесконечная буферизация), исправлено флагом `FLAG_ALLOW_NON_IDR_KEYFRAMES` в `Playback.hlsFactory`; три потока провайдера (`perviy_orig`, `M_HD`, `PERVIY`) играют. Добавлены диагностика и сторож зависания видео (программный видеодекодер; звук не отключается). Не проверено: на настоящем телевизоре (аппаратный декодер, MP2 / AC-3 звук — на эмуляторе MP2 и AC-3 не декодируются, поэтому звука в этих потоках я не слышал).

- [x] Настройка «Приоритет логотипов» (плейлист / программа) с запасным источником и кэшем неудач (12 ч — ошибка сервера и битая картинка, между запусками; 3 мин — нет связи). Не проверено: сохранение списка неудач между запусками (файл не появлялся — ошибки были «сетевые»), 404 на настоящем сервере.

## Виды гида «Категории + каналы» и «Каналы» (2026-09-07)

- [x] Настройка «Вид гида» — четыре вида; правая часть экрана открыта (градиент), программа выезжает из-под списка по →, категории стоят на экране или выдвигаются по ←. Проверено на эмуляторе: оба вида, → и ←, градиент. Не проверено: диагональный градиент под шапкой (не делался), тач, размер «Больше», панель описания в этих видах, настоящий телевизор.

## Колонка плейлистов в гиде (2026-09-05)

- [x] ← в колонке категорий выдвигает список плейлистов со сдвигом экрана. Проверено на эмуляторе (с одним плейлистом, проверка «больше одного» временно снята): выезд колонки, сдвиг категорий и каналов. Не проверено: смена плейлиста из колонки, тач.

## Вид «Список» и шапка гида (2026-08-30)

- [x] Вид «Список»: каналы · передачи канала (шкала прогресса у идущей) · компактные даты; настройки «Шапка гида» (канал + передача / канал / скрыть) и «Описание в ТВ-гиде» (панель со сдвигом). Проверено на эмуляторе: три зоны, панель, все режимы шапки в списке и в таблице. Не проверено: тач, картинка передачи в панели (в EPG тестового плейлиста картинок нет), настоящий телевизор, размер «Больше».

## Правки по отзывам с телевизора (2026-07-12)

- [x] Окно программы: значки архива и «играет» вдвое крупнее, время в панели крупнее, рамка фокуса едет вместе с прокруткой.
- [x] Инфопанель: бейджи с полями, постоянная высота строк (карусель не прыгает).
- [x] Размер интерфейса: меньше / нормальный / больше (540 / 480 / 432 dp), по умолчанию — 480; колонки «О передаче» — долями ширины.
- Проверено на эмуляторе: окно программы, гид, меню (прокрутка), инфопанель — в обычном и очень крупном размере; карусель на одном месте на каналах с архивом и без.
- Проверено на эмуляторе: «О передаче» в трёх размерах — описание занимает ту же долю ширины. В размере по умолчанию (480 dp) меню канала не помещается целиком — три нижних пункта по прокрутке.
- Не проверено: плавность рамки фокуса (по снимкам не видно) и всё перечисленное — на настоящем телевизоре; настройки в очень крупном размере.
